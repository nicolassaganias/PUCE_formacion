# Curso: Innovación Docente y Living Labs
## PUCE Ibarra - Universidad de Girona | Marzo 2026

Curso teórico-práctico sobre sensores ambientales low-cost y cartografía colaborativa para la resiliencia territorial frente al cambio climático.

### Estructura

| Carpeta | Contenido |
|---------|-----------|
| `firmware/` | Códigos Arduino del curso |
| `downloads/` | Guías de instalación: Arduino IDE, driver CH340, librerías |
| `documentacion/` | Diagramas de conexión y montaje de prototipos |

### Sensores trabajados

- **Kit Ciencia (agua):** pH, TDS, turbidez, temperatura, oxígeno disuelto
- **Kit Arquitectura (aire):** temperatura, humedad, CO2, ruido, iluminación
